# Human Flutter Engineering Workflow for Windsurf Cascade

1. **Understand Requirements**: Clarify user goals and inspect `pubspec.yaml`.
2. **Architecture Discovery**: Detect BLoC, Riverpod, or Provider state management.
3. **Design System & Tokens**: Apply `ColorScheme` and `TextTheme`.
4. **Implement UI**: Build declarative Flutter widgets with `const` constructors.
5. **Quality Verification**: Execute `flutter test` and `dart analyze`.
