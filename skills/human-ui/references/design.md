# Human UI Design Reference

> Concise reference for visual hierarchy, human design rules, color systems, and typography.

---

## 1. Core Directives

1. **Eliminate AI Visual Tropes**: Reject gratuitous neon borders, dark cyber glows, multi-stop hero gradients, and arbitrary frosted glass.
2. **Proximity & Cadence**: Group related items closely (4px–8px between label and input); separate distinct sections with generous whitespace (24px–32px).
3. **Card Discipline**: Do not wrap every isolated datum in a card. Use whitespace, subtle dividers, and clean typography.
4. **Color Balance (60-30-10)**: 60% neutral surfaces, 30% content elements, 10% accent/brand. Red is strictly reserved for destructive/error states.
5. **Typographic Scale**: Adhere to the 8-tier scale. Headings must have tight line-heights (1.15–1.25); body text must have comfortable line-heights (1.4–1.6).
